Wiederherstellen

Restore überschreibt die laufende DB — bewusst kein UI-Knopf. Als Ops-Kommando mit Tipp-Bestätigung (RESTORE eintippen):

docker compose run --rm app restore <datei.dump.enc>

Vorab prüfen (ohne die DB anzufassen): docker compose run --rm app restore --test <datei.dump.enc> — entschlüsselt, validiert das Archiv, meldet Objekt-Anzahl & Schema-Stand.

„Veraltet" heißt: das letzte geplante Backup ist älter als 26 Stunden. Jedes geschriebene Backup wird automatisch auf Wiederherstellbarkeit geprüft (Entschlüsselung + Archiv-Validierung) → „Restore getestet".
