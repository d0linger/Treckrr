● gesetzt
Wiederherstellen

„Validieren" entschlüsselt in-memory und prüft das Archiv — ohne die DB anzufassen. Ergebnis erscheint als Meldung oben.

Zerstörerisch: ersetzt alle aktuellen Daten. Nur nach Validierung & Tipp-Bestätigung, admin-only, im Audit protokolliert. Alternativ als Ops-Kommando: docker compose run --rm app restore <datei.dump.enc>.

„Veraltet" = letztes geplantes Backup älter als 26 Stunden. Jedes geschriebene Backup wird automatisch auf Wiederherstellbarkeit geprüft (Entschlüsselung + Archiv-Validierung) → „Restore getestet".
